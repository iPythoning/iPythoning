### Stack & Approach

- **Agents over scripts** — Multi-tenant, cron-driven, memory-backed AI workers beat hand-coded automation.
- **Tenant isolation is a hard rule** — Every `system_settings` row is scoped by `tenant_id`. Learned the hard way.
- **Cherry-pick, don't import** — Borrow patterns from open-source giants; never adopt the brand or the dependency graph.
- **Don't break A while fixing B** — One service at a time. Verify deploy beyond the health check.
- **Ship beats perfect** — I build tools to solve my own problems, then open-source the parts that should belong to everyone.
